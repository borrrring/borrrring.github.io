## 📟 STM32 最小系统 + PWM 输出代码（标准库）

以下代码基于 **STM32F103C8T6**（蓝色 pill），使用 **标准外设库**，实现：
- 系统时钟配置（72MHz）
- GPIO 点亮板载 LED（PC13）
- 定时器 TIM2 的通道 2 输出 PWM（频率 1kHz，占空比 50%）

### 1. 新建工程步骤（摘要）
- 选择芯片 STM32F103C8
- 加入标准库文件：`stm32f10x_gpio.c`, `stm32f10x_rcc.c`, `stm32f10x_tim.c`, `misc.c`
- 配置系统时钟在 `SystemInit()` 中默认 72MHz（内部HSE+ PLL）

### 2. main.c

```c
#include "stm32f10x.h"

void GPIO_Config(void) {
    GPIO_InitTypeDef GPIO_InitStruct;

    // 使能 GPIOA（PA0用于TIM2_CH2）和GPIOC（PC13 板载LED）
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA | RCC_APB2Periph_GPIOC, ENABLE);

    // 配置 PA0 为复用推挽输出（用于PWM）
    GPIO_InitStruct.GPIO_Pin = GPIO_Pin_0;
    GPIO_InitStruct.GPIO_Mode = GPIO_Mode_AF_PP;   // 复用推挽
    GPIO_InitStruct.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStruct);

    // 配置 PC13 为推挽输出（LED）
    GPIO_InitStruct.GPIO_Pin = GPIO_Pin_13;
    GPIO_InitStruct.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStruct.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOC, &GPIO_InitStruct);

    // 点亮LED（PC13低电平有效）
    GPIO_ResetBits(GPIOC, GPIO_Pin_13);
}

void TIM_PWM_Config(void) {
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStruct;
    TIM_OCInitTypeDef TIM_OCInitStruct;

    // 使能 TIM2 时钟
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);

    // 定时器基础配置：
    // 72MHz / (Prescaler+1) = 定时器频率
    // 例如：Prescaler = 71 → 72MHz / 72 = 1MHz（1us）
    // 再设置 Period = 999 → 1MHz / 1000 = 1kHz
    TIM_TimeBaseStruct.TIM_Prescaler = 71;     // 分频系数 = 71+1 = 72
    TIM_TimeBaseStruct.TIM_CounterMode = TIM_CounterMode_Up;
    TIM_TimeBaseStruct.TIM_Period = 999;       // 自动重装载值
    TIM_TimeBaseStruct.TIM_ClockDivision = TIM_CKD_DIV1;
    TIM_TimeBaseStruct.TIM_RepetitionCounter = 0;
    TIM_TimeBaseInit(TIM2, &TIM_TimeBaseStruct);

    // 配置通道2（PA1，这里我们实际用PA0对应TIM2_CH1，修正为通道1）
    // 注意：TIM2_CH1对应PA0，TIM2_CH2对应PA1
    // 我们使用CH1，所以PA0是正确的。
    TIM_OCInitStruct.TIM_OCMode = TIM_OCMode_PWM1;
    TIM_OCInitStruct.TIM_OutputState = TIM_OutputState_Enable;
    TIM_OCInitStruct.TIM_Pulse = 500;          // 占空比 = 500/1000 = 50%
    TIM_OCInitStruct.TIM_OCPolarity = TIM_OCPolarity_High;
    TIM_OC1Init(TIM2, &TIM_OCInitStruct);      // 注意是 OC1，对应通道1

    // 使能预装载寄存器
    TIM_OC1PreloadConfig(TIM2, TIM_OCPreload_Enable);
    TIM_ARRPreloadConfig(TIM2, ENABLE);

    // 启动 TIM2
    TIM_Cmd(TIM2, ENABLE);
}

int main(void) {
    SystemInit();        // 配置系统时钟 72MHz
    GPIO_Config();
    TIM_PWM_Config();

    while(1) {
        // 主循环什么都不做，PWM由硬件自动输出
    }
}
```

### 3. 接线（如果用板载LED则不用接线）
- PA0 连接到示波器或LED（串联1k电阻限流）查看PWM波形
- PC13 已连接板载LED

### 4. 验证

## 📚 第1小时：C语言三要素（只看结论，先背下来）

### 1. `volatile`
- **背法：** “编译器不要优化我，每次从内存读”  
- **必记例子：** 中断中修改的变量必须加 volatile。  
- 不深究原理，面试问“什么时候用volatile”就答：“中断共享变量、硬件寄存器、多线程共享变量”。

### 2. `static`
- **局部static：** 函数退出值不丢，只初始化一次（例如计数器）  
- **全局static：** 不允许别的文件访问（文件作用域）  
- 背：static int x = 0; 在函数内只会初始化一次，之后每次调用x的值递增。

### 3. 结构体内存对齐
- **结论：** `struct { char a; int b; short c; }` 在32位ARM下占 **12字节**（不是7，因为要做对齐）  
- **原因：** CPU访问对齐地址最快，编译器会自动填充空位。

**小练习：** 你写一个结构体 `struct { char a; char b; int c; }` 猜占多少字节？答案：8字节（a和b扎堆占2字节，c从偏移4开始，总大小8）。


## 🧠 第2小时：指针与函数指针（只理解概念）

- **数组名 vs 指针：**  
  `int a[10]; sizeof(a) = 40`（数组大小）  
  `int *p = a; sizeof(p) = 8`（指针大小）

- **函数指针：** 重点是嵌入式里常用来做回调或中断向量表。  
  ```c
  void myFunction(void) { /* do something */ }
  void (*fp)(void) = myFunction;
  fp();  // 调用函数
  ```
  不需要理解底层，会写这个形式就够了。
