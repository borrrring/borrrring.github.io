# 指针函数

假设我们的单片机硬件底层收到了数据，然后数据被放到了一个接收缓冲区里面，那么函数应该通过什么方式拿到这些数据呢？
在底层的数组中有一个接收缓冲区，数组会放在驱动文件中，此时底层提供一个接口
这里其实进行了封装资源地址
```
#define UART_RX_SIZE 128
static uint8_t uart_rx_buf(UART_RX_SIZE);
//用static声明 可以保证在函数结束之后 其值依旧存在 这样上层可以一直读到这个变量

//如果只想让上层读到这个缓冲区 还可以加上const修饰 上层就无法进行修改了
uint8_t *UART_GetRxBuffer(void) //通过该函数返回缓冲区中的数据地址
{
	//如果在函数中设置变量，那么函数结束的时候，这个变量也消失了，上层就读不到了
	return uart_rx_buf;
}

uint8_t *buff;
buff = UART_GetRxBuffer();
```
指针函数的典型用途就是把某个资源地址通过函数返回给调用者
