# 位操作

`& `  -按位与
`｜` -按位或
`～` -按位非
`^`  -按位异或
`<<` -左移 移动三位就是从最右边第一位开始移动三位 也就是移动到从右数第四个位置上
`>>` -右移

掩码(mask)：以8位为例其实就是 0000 0001

```
eg:把第三位拉成1 按位或操作
就是先得到一个只有第三位为1，其余位为0的掩码
然后将要改变的寄存器的所有位与这个掩码做按位或操作
这样可以保证 其他位该是啥还是啥 又因为只有第三位为1 其按位或之后就变为1了
也就可以实现只有将第三位拉成1了
```

```
eg:改位和查位分开看 按位与操作
清零是  取反后的掩码+按位与
读位是  原掩码+按位与 //这里的读位是指你具体想知道哪一位是什么
```

```
eg:需要寄存器中的第四位和第五位（从0位开始）输入到外设
就需要先将字段挪到最右端，然后再截出来
就是将第四位和第五位向右挪动4位 分别到第0位和第1位的位置上
然后再和掩码（0000 0011）做按位与操作 //这里因为是要用两位 所以掩码将两位设为1
```

使用上述变量类型 是保证其位宽一致

# 宏定义

宏先于编译发生，它不是运行时变量，而是预处理阶段的名字替换

```
#ifndef _LED_H
#define _LED_H

#endif
```

头文件只会出现一次，上面的条件编译的目的就是为了防止一个头文件被重复包含
换句话说就是，如果在不同的.c文件中，都调用了这个头文件，同时其中的一个.c文件调用了同样包含了这个头文件的.c文件，那么当第一次发现这个头文件的时候会加载，而第二次发现这个头文件的时候就会跳过了。

将固定地址、指针类型、解引用合在一起，才让硬件看起来像一个变量，如果我们对这个硬件变量赋值，其实就是在操作硬件寄存器

# 指针

指针决定怎么读地址，地址相同，不代表访问方式相同，其类型会变成CPU的读取宽度
比如说用unit8_t读就是按一个字节读，如果使用了错误的类型就可以会读到其他的内容

```
volatile //告诉程序这个值是会不断变化的 不要缓存 每次都去原地址访问
```
# 联合体

里面的变量指的都是同一块地址，通常用来拆解寄存器
```
union IntBytes{
	uint32_t word;//4字节
	uint8_t byte[4];//同一个4字节，但是按字节访问
}
```

# 变量使用前缀

```
extern   //生命别处已经定义的变量，适合共享信息
static   //文件内可见/局部变量保留生命周期  不会随着函数的开始结束而圆周率进行修改
const    //初始化后不可改 用来修饰常量 比如说pi=3.14 用const可以节省内存 会放到flash上
```
