## 三个函数

看 [`port.c`](vscode-webview://11buap8cfk3j0slth0dj5r6f3dnmqq4qf6rmrnp8c3gcqggm7418/FreeRTOS-LTS/FreeRTOS/FreeRTOS-Kernel/portable/GCC/ARM_CM3/port.c#L123-L125)，三个需要挂钩的函数是：

| FreeRTOS 函数名          | 对应异常                  | 向量表位置  | 中断向量名             |
| --------------------- | --------------------- | ------ | ----------------- |
| `vPortSVCHandler`     | SVC (Supervisor Call) | 第 11 项 | `SVC_Handler`     |
| `xPortPendSVHandler`  | PendSV                | 第 14 项 | `PendSV_Handler`  |
| `xPortSysTickHandler` | SysTick               | 第 15 项 | `SysTick_Handler` |

## 向量表在哪

在 PlatformIO 工具链提供的 CMSIS 启动文件里：

```
.platformio/packages/framework-cmsis-stm32f1/Source/Templates/gcc/startup_stm32f103xb.s
```

截取关键部分（第 142-146 行、第 223-233 行）：

```asm
g_pfnVectors:
  ...
  .word SVC_Handler         @ 第 11 项
  .word PendSV_Handler      @ 第 14 项
  .word SysTick_Handler     @ 第 15 项
  ...

  .weak SVC_Handler
  .thumb_set SVC_Handler,Default_Handler

  .weak PendSV_Handler
  .thumb_set PendSV_Handler,Default_Handler

  .weak SysTick_Handler
  .thumb_set SysTick_Handler,Default_Handler
```

这些是 **weak 符号**——只要你在项目的任意 `.c` 文件中定义了同名函数，链接器就会用你的版本覆盖默认的 `Default_Handler`（死循环）。

## 建议的做法

**你需要在 `src/` 目录下创建一个文件**（比如 `src/FreeRTOS_hooks.c`），用 GCC 的 `alias` 属性把 CMSIS 的中断名映射到 FreeRTOS 的 port 函数名上：

```c
/* FreeRTOS_hooks.c — 将 FreeRTOS ARM_CM3 port 中断挂钩到 CMSIS 向量表 */

extern void vPortSVCHandler(void);
extern void xPortPendSVHandler(void);
extern void xPortSysTickHandler(void);

/* GCC weak alias: 覆盖 startup 文件中的 weak 默认值，指向 FreeRTOS 实现 */
void SVC_Handler    (void) __attribute__((alias("vPortSVCHandler")));
void PendSV_Handler (void) __attribute__((alias("xPortPendSVHandler")));
void SysTick_Handler(void) __attribute__((alias("xPortSysTickHandler")));
```

这个文件可以放在：

```
src/FreeRTOS_hooks.c
```

**注意**：不要试图去修改 PlatformIO 工具链里的 `startup_stm32f103xb.s`，那是系统文件，下次重装/更新 PlatformIO 就被覆盖了。

## 必须同时做的配套工作

1. **在 `FreeRTOSConfig.h` 中设置 `configCHECK_HANDLER_INSTALLATION`** — 如果设为 1，`xPortStartScheduler()` 会运行时检查向量表里 SVC 和 PendSV 是否确实指向了 FreeRTOS 的函数（见 `port.c` 第 282-301 行），这正好验证你的挂钩是否成功。
    
2. **确认 `FreeRTOSConfig.h` 中定义了 `configCPU_CLOCK_HZ`、`configTICK_RATE_HZ` 等参数**，因为 `vPortSetupTimerInterrupt()` 会用到它们配置 SysTick。
    
3. **`include/` 下的文件路径**已经在 `platformio.ini` 中通过 `-Iinclude` 加入了构建，所以 `FreeRTOSConfig.h` 能被找到。
