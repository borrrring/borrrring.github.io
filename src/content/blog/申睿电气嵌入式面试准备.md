## 二、C 语言 & STM32 基础（必考）

### 2.1 C 语言高频题

#### volatile 关键字
- 告知编译器该变量可能被意外修改，禁止优化
- 每次使用都从内存重新读取，不缓存到寄存器
- **应用场景：** 中断中修改的全局变量、多线程共享变量、硬件寄存器地址

```c
// 典型用法：中断标志位
volatile uint8_t flag = 0;
void TIMx_IRQHandler(void) {
    flag = 1;  // 编译器不会优化掉这个赋值
}
while (!flag); // 每次都会从内存读取，不会死循环
```

#### static 关键字
- **局部变量：** 保持值持久，函数退出不销毁，只初始化一次
- **全局变量/函数：** 限定在本文件作用域，外部文件不可见

#### const 关键字
- 修饰变量：变为只读
- 修饰指针：`const int *p`（指向内容不可改）、`int * const p`（指针本身不可改）
- **与 #define 区别：** const 有类型检查，#define 是文本替换；const 在内存中有实体，#define 在预处理器阶段完成

#### 结构体内存对齐
```c
struct example {
    char a;    // 1字节  → 偏移0
    int b;     // 4字节  → 偏移4（对齐到4的倍数）
    short c;   // 2字节  → 偏移8
}; // 总大小12字节（最大成员对齐到4的倍数 → 10补齐到12）
```

**原因：** CPU 访问对齐数据效率高，有些硬件不支持非对齐访问。

#### 大端与小端
- **大端：** 低地址存高位字节（如网络字节序）
- **小端：** 低地址存低位字节（如 x86、ARM 默认）

```c
// 判断方法
int x = 0x12345678;
char *p = (char *)&x;
if (*p == 0x78) printf("小端");
else printf("大端");
```

#### 指针与数组
- `int a[10];` — `a` 是数组首地址常量，`sizeof(a)` = 40
- `int *p = a;` — `p` 是指针变量，`sizeof(p)` = 8（64位）
- 数组在函数传参时退化为指针

#### 函数指针
```c
// 嵌入式常见用法：回调函数、中断向量表
void (*func_ptr)(void);
func_ptr = &some_function;
func_ptr(); // 调用
```

#### extern "C"
- C++ 中声明 C 语言编译链接方式的函数
- 防止 C++ 名字修饰（name mangling）导致链接失败
- **应用场景：** C 库函数（如 `printf`）、C 编写的固件库

### 2.2 STM32 高频题

#### STM32 上电启动流程
1. 上电复位，CPU 从 **0x00000000** 取栈顶指针（MSP）
2. 从 **0x00000004** 取复位向量 → 跳转到 Reset_Handler
3. Reset_Handler 执行：初始化时钟（HSE → PLL）、初始化 .bss/.data 段
4. 调用 `SystemInit()` 配置系统时钟
5. 跳转到 `main()` 函数

#### GPIO 工作模式
| 模式 | 用途 |
|------|------|
| 推挽输出 | 普通输出，高低电平都能驱动 |
| 开漏输出 | 需要外接上拉电阻，实现"线与"（如 I2C） |
| 浮空输入 | 不拉不推，电平由外部决定 |
| 上拉/下拉输入 | 默认电平确定 |
| 复用推挽/开漏 | 外设功能（如 UART TX） |

#### 中断流程
1. 外设触发中断请求
2. NVIC 判断优先级是否高于当前运行
3. 保护现场（压栈：R0-R3、R12、LR、PC、xPSR）
4. 跳转到中断向量表对应的 ISR
5. 执行 ISR → 清除中断标志位
6. 退出中断 → 恢复现场（出栈）
7. 返回被中断的代码继续执行

**注意事项：** ISR 要短、快；不要调用 `printf`、`malloc` 等不可重入函数；共享变量加 `volatile`

#### 定时器分类
| 类型 | 特性 | 用途 |
|------|------|------|
| 基本定时器（TIM6/7） | 纯定时，无外部 IO | 定时中断、触发 DAC |
| 通用定时器（TIM2~5） | 有 IO，PWM/输入捕获 | 通用 PWM、脉冲计数 |
| 高级定时器（TIM1/8） | 带互补PWM+死区+刹车 | **电机控制、数字电源** |

#### DMA
- 无需 CPU 参与，外设 ↔ 内存直接传输数据
- **适用场景：** ADC 连续采样、SPI/UART 收发、内存拷贝
- 优点：降低 CPU 占用，适合大批量数据

#### 看门狗
| 类型 | 时钟源 | 特点 |
|------|--------|------|
| 独立看门狗 IWDG | LSI（40kHz） | 独立于主时钟，更可靠 |
| 窗口看门狗 WWDG | APB1 | 必须在时间窗口内喂狗 |

#### I2C vs SPI vs UART

| 特性 | I2C | SPI | UART |
|------|-----|-----|------|
| 线数 | 2（SDA+SCL） | 4（MOSI+MISO+SCK+CS） | 2（TX+RX） |
| 通信方式 | 半双工 | 全双工 | 全双工 |
| 速率 | 标准100k/400k | 可达数十MHz | 通常115200~若干M |
| 设备数 | 多设备（地址寻址） | 一主多从（CS片选） | 点对点 |
| 同步/异步 | 同步 | 同步 | 异步（需波特率匹配） |

## 三、数字电源方向（重点补）

> 这是和岗位匹配度最高的技术领域，面试大概率围绕这个方向展开。

### 3.1 基本电源拓扑

#### Buck 降压电路

```
Vin ──┤ SW ├── L ── Vout
         │        │
         D        C
         │        │
        GND ──── GND
```

- **原理：** 开关管导通时 Vin 给 L 储能 + C 充电；开关管关断时 L 通过二极管续流放电
- **占空比：** D = Vout / Vin（连续导通模式 CCM）
- **关键波形：** SW 节点电压是方波（Vin~0）；电感电流是三角波

#### Boost 升压电路

```
Vin ── L ──┤ SW ├── D ── Vout
            │        │
            Q        C
            │        │
           GND ──── GND
```

- **原理：** 开关管导通时 L 储能；关断时 L 释放能量叠加到 Vin 输出
- **占空比：** D = 1 - Vin / Vout

#### Buck-Boost 升降压
- 输出反极性（Vout 为负）
- D = Vout / (Vin + Vout)

#### LLC 半桥谐振
- 通过谐振腔（Lr + Cr + Lm）实现零电压开关（ZVS）
- 效率高、EMI 小，常用于中大功率隔离电源

### 3.2 PWM 在电源中的特殊要求

#### 死区时间（Dead Time）
```
   CH1 ┌──┐    ┌──┐    ┌──
       │  │    │  │    │
       ┘  └────┘  └────
   CH2 ──┐    ┌──┐    ┌──
         │    │  │    │
         └────┘  └────┘
        ←死区→
```
- 半桥/全桥中上下管不能同时导通（否则短路！）
- 在 PWM 切换时插入死区，等一个管完全关断再开另一个
- STM32 高级定时器（TIM1/8）支持硬件自动插入死区

#### 互补 PWM + 刹车功能
- 高级定时器可以输出一对互补 PWM（CH1 + CH1N）
- 刹车输入（BKIN）可以硬件强制关断 PWM，用于过流保护

#### 开关频率选择
| 频率 | 优点 | 缺点 |
|------|------|------|
| 低频（~50kHz） | 开关损耗小 | 变压器/电感大 |
| 高频（100k~1MHz） | 磁性元件小 | 开关损耗大，驱动困难 |

#### PWM 分辨率
```
分辨率 = 定时器时钟 / PWM频率
例如：72MHz / 100kHz = 720 步 → 约 9.5 位
STM32G4 HRTIM 可达 184ps 分辨率
```

### 3.3 采样与反馈

#### 数字电源闭环控制框图

```
                 PID
  Vref ──┤+├──→ 控制器 ──→ PWM发生器 ──→ 功率级 ──→ Vout
         ↑                                          │
         │                                          │
         └──────── ADC采样 ←────── 分压 ────────────┘
```

#### ADC 采样时序要点
- PWM 开关动作会产生噪声，不能在开关瞬间采样
- 需要在开关管稳定导通的"中间时刻"触发 ADC
- STM32 可以通过定时器的 **TRGO（触发输出）** 来触发 ADC 启动
- 高级定时器支持在特定的 PWM 计数值时刻触发 ADC

#### 软件滤波方法

**滑动平均滤波：**
```c
#define FILTER_LEN 8
uint16_t buffer[FILTER_LEN];
uint8_t index = 0;
uint32_t sum = 0;

uint16_t filter(uint16_t adc_val) {
    sum -= buffer[index];
    sum += adc_val;
    buffer[index] = adc_val;
    index = (index + 1) % FILTER_LEN;
    return sum / FILTER_LEN;
}
```

**一阶低通滤波：**
```c
// y[n] = α * x[n] + (1-α) * y[n-1]
#define ALPHA 0.1f  // 截止频率 ≈ ALPHA/(2π*Ts)
uint16_t lowpass_filter(uint16_t raw, uint16_t prev) {
    return (uint16_t)(ALPHA * raw + (1-ALPHA) * prev);
}
```

#### PID 控制算法

**位置式 PID：**
```c
typedef struct {
    float Kp, Ki, Kd;
    float integral;
    float prev_error;
    float out_max, out_min;  // 输出限幅
} PID_t;

float PID_Calc(PID_t *pid, float setpoint, float measurement) {
    float error = setpoint - measurement;
    
    // 比例项
    float P = pid->Kp * error;
    
    // 积分项（带限幅防积分饱和）
    pid->integral += error;
    if (pid->integral > pid->out_max / pid->Ki)
        pid->integral = pid->out_max / pid->Ki;
    if (pid->integral < pid->out_min / pid->Ki)
        pid->integral = pid->out_min / pid->Ki;
    float I = pid->Ki * pid->integral;
    
    // 微分项
    float D = pid->Kd * (error - pid->prev_error);
    pid->prev_error = error;
    
    float output = P + I + D;
    
    // 输出限幅
    if (output > pid->out_max) output = pid->out_max;
    if (output < pid->out_min) output = pid->out_min;
    
    return output;
}
```

**增量式 PID：**
```c
// Δu = Kp*(e(n)-e(n-1)) + Ki*e(n) + Kd*(e(n)-2e(n-1)+e(n-2))
// u(n) = u(n-1) + Δu
```

### 3.4 保护逻辑

| 保护类型 | 触发条件 | 处理方式 |
|---------|---------|---------|
| OCP 过流保护 | 采样电阻电压 > 阈值 | 硬件比较器快速关断PWM + 软件记录 |
| OVP 过压保护 | Vout > 阈值 | 停止 PWM，开启放电 |
| OTP 过温保护 | NTC 温度 > 阈值 | 降额运行或关机 |
| UVLO 欠压锁定 | Vin < 阈值 | 不启动，防止 MOSFET 不完全导通 |

**软硬件协同保护架构：**
- **硬件层：** 比较器 + 刹车输入（BKIN），微秒级响应
- **软件层：** ADC 采样检测，毫秒级响应，记录故障码

### 3.5 数字电源常用芯片 & 器件

| 类别 | 型号 |
|------|------|
| 半桥驱动 | IR2104、IR2110、IR21867、EG2104 |
| 电流检测 | INA282、AD8418、ACS712 |
| 隔离运放 | AMC1301、ISO124 |
| 数字隔离 | ISO7221、Si862x |
| 栅极驱动变压器 | 各种绕线式 |

## 四、通用嵌入式设计题

### Q1：单片机上电没转，排查步骤

1. **量电源：** VDD 引脚电压正常？3.3V
2. **复位引脚：** NRST 电平正常？不是一直低电平
3. **晶振起振：** 示波器 X10 档测 OSC_IN/OSC_OUT，看是否有波形
4. **BOOT 引脚：** BOOT0/BOOT1 配置是否正确（通常 BOOT0 拉低进 Flash 启动）
5. **SWD 连接：** 调试器能否识别到芯片？能识别说明核心没问题
6. **电源纹波：** 大纹波可能导致反复复位

### Q2：如何用 STM32 实现数字电源恒压输出？

1. **硬件：** 输出电压经电阻分压 → 运放跟随 → STM32 ADC 输入
2. **软件：**
   - 定时器输出 PWM（开关管驱动）
   - ADC 定时采样输出电压（在 PWM 开关噪声稳定后触发）
   - 软件滤波（滑动平均/低通）
   - PID 计算 → 调整 PWM 占空比
   - 闭环控制直到 Vout = Vref

3. **保护：** 过流/过压/过温保护逻辑

### Q3：PWM 频率怎么选？

- **磁性元件：** 频率高 → 变压器/电感小 → 成本低体积小
- **开关损耗：** 频率高 → MOSFET 开关损耗大 → 发热
- **典型范围：** 50kHz~500kHz（中小功率），LLC 可达 1MHz
- **折中：** 根据功率等级选择，常见 100kHz

### Q4：模拟 PWM vs 软件 PWM

| | 模拟 PWM | 软件 PWM |
|--|---------|---------|
| 响应速度 | 快（ns级） | 慢（受 MCU 处理周期限制） |
| 灵活性 | 固定，改参数要换电阻电容 | 随时可调参数 |
| 适用场景 | 纯硬件电源控制 | 数字电源、需要算法调节 |

### Q5：MCU 选型考虑因素

性能（主频/Flash/RAM）→ 外设需求（PWM通道数/ADC精度/CAN）→ 功耗 → 成本 → 工作温度 → 封装 → 供货稳定性 → 开发工具链成熟度

### Q6：MCU vs DSP vs FPGA

| | MCU | DSP | FPGA |
|---|-----|-----|------|
| 定位 | 控制 | 数字信号处理 | 灵活硬件逻辑 |
| 特点 | 外设丰富 | 乘加指令/MAC | 并行/可重构 |
| 电源应用 | 控制+PWM+通信 | 复杂算法 | 高速PWM+多路并行 |
| 数字电源场景 | 主流方案（STM32G4） | 高精度算法 | 极高开关频率 |

### 5.1 项目简介（1分钟版）

> "我在上一家公司独立负责了一个基于 STM32F103 的嵌入式控温系统开发。系统是电池供电，通过 PWM 控制加热功率，用 DS18B20 测温，ADC 检测电池电压，实现了温度闭环控制。虽然名义上是控温系统，但核心逻辑和数字电源是相通的——ADC 采样 → MCU 运算 → PWM 控制功率输出，还做了过流、过温、低电量等多重保护。"

### 5.2 技术细节怎么讲

| 原始描述 | 面试时升级版表述 |
|---------|---------------|
| PWM 控制加热 | "用 PWM 控制加热功率，相当于 Buck 电路的功率控制思路，需要根据负载调整占空比" |
| ADC 读电池电压 | "做了电池电压采样，用软件滤波解决 ADC 阈值抖动问题，实现了低电量自动保护（类似 UVLO）" |
| 过流、过温保护 | "设计了软硬件协同保护：硬件比较器快速响应，软件做故障记录和恢复管理" |
| 30+ 轮实测迭代 | "积累了丰富的边界情况处理经验，比如温度校准、ADC 采样时序优化、状态切换的毛刺消除" |
| 按功能拆成独立模块 | "把 ADC/PWM/LED/DS18B20/充电管理等拆成独立模块，方便后续维护和移植" |

### 5.3 如何回应"没有电源经验"的质疑

> "我理解数字电源有自己的领域知识，比如电源拓扑、闭环控制这些。但我有扎实的 STM32 嵌入式基础，做过 ADC 采样、PWM 控制、保护逻辑这些和电源开发相通的工作。我对电源方向很感兴趣，学习能力也比较强——之前控温系统的 PID 控制就是我边学边做的，两周就调通了闭环。**基础能力到位了，领域知识我可以很快补齐。**"
